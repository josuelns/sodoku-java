# sodoku-java

> Gerar, validar e resolver grades de Sudoku respeitando as regras clássicas do jogo.

## Problema

Gerar, validar e resolver grades de Sudoku respeitando as regras clássicas do jogo.

## Solução

Aplicação Java orientada a objetos com algoritmos de validação de linha/coluna/bloco e resolução por backtracking.

## Stack

- Java
- OOP
- Lógica
